# 采集节点设计细节（STM32F103）

> v1.1 ｜ 2026-08-17 ｜ 对应总体框架 §4 ｜ 本文只定义设计，不含代码实现。
> 目标：一套传感器电路，两种通信变体（有线 RS485 / 无线 nRF24L01），固件差异仅限通信层。
> v1.1 新增：温湿度传感器升级为 SHT30（I2C），DHT11（单总线）降级为可选低成本方案；传感器协议覆盖 UART/SPI/I2C/ADC/单总线。

---

## 1. 节点类型与硬件差异

| 差异项 | 有线节点 | 无线节点 |
|---|---|---|
| 通信外设 | USART1 + MAX485/SP3485 | SPI1 + nRF24L01 |
| 占用引脚 | PA8 / PA9 / PA10 | PA3~PA7 / PB0 |
| 电源 | 总线供电或独立 5V | 独立 5V（无线功耗高） |
| 固件差异 | Modbus 从站走串口 | Modbus 帧走 SPI 无线（32B 单包） |
| 传感器部分 | **完全相同**（PA0/PA1/PA2 + PB1/PB6/PB7） | 完全相同 |

设计原则：传感器与采样电路做成公共部分，两种节点共用；通信层独立，固件通过编译宏区分（如 `NODE_LINK_RS485` / `NODE_LINK_RF24`）。

## 2. 引脚分配表

### 2.1 公共部分（两种节点一致）

| 功能 | 引脚 | 外设 | 说明 |
|---|---|---|---|
| MQ-2 烟雾 | PA0 | ADC1_CH0 | 模拟输出（模块 5V 供电，AO 分压后接入） |
| 电压采样 | PA1 | ADC1_CH1 | 电阻分压（如 30k/10k） |
| 电流采样 | PA2 | ADC1_CH2 | ACS712 输出（5V 供电，分压/偏置匹配 3.3V 量程） |
| SHT30 温湿度 | PB6 / PB7 | I2C1（SCL/SDA） | 数字温湿度，地址 0x44；软件 I2C 模拟（见 §3.1） |
| DHT11（可选） | PB1 | GPIO 推挽输出/开漏上拉输入 | 单总线低成本替代方案，编译宏切换，4.7kΩ 上拉 |
| 本地告警 | PB0 | GPIO 推挽输出 | 蜂鸣器（三极管驱动）/ LED；无线节点改作 IRQ 用 |
| SWD 调试 | PA13/PA14 | 保留 | 不占用 |

ADC 方案：**ADC1 多通道（CH0/1/2）+ DMA 循环采样**，主循环或定时器读取，软件取平均。

### 2.2 有线节点（USART1 + MAX485）

| 功能 | 引脚 | 说明 |
|---|---|---|
| USART1_TX | PA9 | → MAX485 DI |
| USART1_RX | PA10 | ← MAX485 RO |
| 方向控制 DE/RE | PA8 | GPIO 推挽：发送拉高、接收拉低；收发切换预留 tT 延时 |
| 终端电阻 | A/B 总线 | 总线两端各 120Ω |

波特率 9600-8-N-1，半双工，一问一答。

### 2.3 无线节点（SPI1 + nRF24L01）

| 功能 | 引脚 | 说明 |
|---|---|---|
| SPI1_SCK | PA5 | → SCK |
| SPI1_MISO | PA6 | ← MISO |
| SPI1_MOSI | PA7 | → MOSI |
| CSN | PA4 | GPIO 软件片选（nRF24L01 要求 GPIO 控制） |
| CE | PA3 | GPIO：Standby/RX/TX 模式切换 |
| IRQ | PB0 | GPIO/EXTI10 外部中断：收数据/发送完成/重传超时 |

要点：nRF24L01 工作电压 3.3V，SPI 速率建议 ≤ 2MHz（模块时序余量），空中速率 1Mbps，增强型 ShockBurst（自动 ACK + 自动重传）。

## 3. 传感器驱动要点

### 3.1 SHT30 温湿度（I2C，主方案）

**关键参数**
- I2C 地址：0x44（ADDR 引脚拉高为 0x45，可挂第二颗）；供电 3.3V
- 精度：±0.2℃ / ±2%RH（典型），远高于 DHT11（±2℃ / ±5%RH）
- 单次测量命令：`0x2C 0x06`（高重复性），转换时间约 4~15ms
- 返回 6 字节：温度 MSB/LSB/CRC + 湿度 MSB/LSB/CRC——**每 2 字节带 1 字节 CRC8 校验**
- 换算公式：
  - 温度：`T = -45 + 175 × (raw / 65535)`（℃）
  - 湿度：`RH = 100 × (raw / 65535)`（%RH）
- **读取间隔 ≥ 100ms 即可**（远快于 DHT11 的 1s），轮询周期可提到 500ms 级，数据更实时

**为什么用软件 I2C 而不是硬件 I2C**（面试必聊的坑）
- STM32F103 硬件 I2C 模块存在已知 errata（EV5/EV7 事件处理异常、总线状态错误后卡死），业界普遍避开
- 方案：**GPIO 模拟 I2C**（SCL/SDA 开漏 + 4.7kΩ 上拉，位操作实现 START/STOP/ACK），标准模式 100kHz
- 面试话术："硬件 I2C 有 errata，用软件模拟规避，代价是占用 CPU，但 100kHz 下开销可忽略，且引脚可任意指定"

**数据集成（分层透明的关键点）**
- SHT30 是**节点内部传感器**，数据进 40001/40002 寄存器后，网关完全无感——**Modbus 契约不受影响**
- 面试价值：传感器层协议（I2C）与应用层协议（Modbus）解耦，改传感器不碰通信层

### 3.2 DHT11（单总线，可选低成本方案）

- 编译宏 `TEMP_SRC_SHT30` / `TEMP_SRC_DHT11` 二选一，寄存器映射与网关逻辑不变
- 时序流程：拉低 ≥18ms 起始 → 拉高 20~40μs → 等响应（80μs 低 + 80μs 高）→ 40bit 数据
- 数据格式：湿度整数 + 湿度小数 + 温度整数 + 温度小数 + 校验和（= 前四字节之和）
- 数据位判定：高电平持续 26~28μs = 0，70μs = 1（**时序敏感，需关中断/临界区保护**）
- **读取间隔 ≥ 1s**：DHT11 采样周期约 1~2s，频繁读会失败
- 校验失败丢弃本轮数据，连续失败置状态字故障位
- 对比话术（面试可用）：DHT11 便宜但精度低、时序敏感、无标准协议；SHT30 是标准 I2C + CRC 校验，可靠性高——这也是项目选型升级的理由

### 3.3 MQ-2（烟雾/可燃气体）

- 上电预热 ≥60s 再取数（加热器稳定），期间数据标记"预热中"
- 简化方案：直接上报 ADC 原始值（0~4095）+ 模块电位器调灵敏度，标定曲线后置阶段再细化
- 增强方案（后续）：Rs/R0 比值 → 查气体浓度曲线（对数坐标），ppm 上报
- 读数策略：ADC 多次采样取中值滤波，抑制噪声

### 3.4 电压采样（分压）

- 换算公式：`U = ADC/4096 × 3.3 × (R1+R2)/R2`
- 例：30k/10k 分压 → 量程约 0~13.2V（充电桩直流母线/电池电压）
- 注意：输入引脚有 3.3V 上限，分压比按目标量程留 20% 裕量

### 3.5 电流采样（ACS712）

- 型号：ACS712-20A（灵敏度 100mV/A，VCC=5V 时零流输出 2.5V）
- 换算公式：`I = (V_out - VCC/2) / 灵敏度`
- **电平匹配**：5V 供电输出 0.5~4.5V，需分压（如 10k/4.7k ≈ 0.68）压入 3.3V 量程，或选 3.3V 供电模块（灵敏度按比例降低，注意换算系数）
- 选型备注：方案文档里明确"5V 供电 + 分压"，避免实际接线时烧 ADC

## 4. Modbus 从站与寄存器区

### 4.1 寄存器映射（与 project-plan §4.1 一致）

| 寄存器 | 含义 | 类型 | 说明 |
|---|---|---|---|
| 40001 | 温度 | int16 ×10（0.1℃） | SHT30（I2C）；可选 DHT11 |
| 40002 | 湿度 | uint16 ×10（0.1%RH） | SHT30（I2C）；可选 DHT11 |
| 40003 | 烟雾浓度 | uint16 | ADC 原始值（0~4095） |
| 40004~40005 | 电压 | uint32 ×100（0.01V） | 32 位大端 |
| 40006~40007 | 电流 | uint32 ×1000（0.001A） | 32 位大端 |
| 40008 | 节点状态字 | uint16 | bit 定义见下 |

### 4.2 状态字 bit 定义（40008）

| bit | 含义 | 置位条件 |
|---|---|---|
| 0 | 传感器故障 | SHT30 连续 N 次 CRC 校验失败 / ADC 通道异常（DHT11 方案为连续 N 次校验和失败） |
| 1 | 温度越限 | 温度超阈值（±范围） |
| 2 | 湿度越限 | 湿度超阈值 |
| 3 | 烟雾越限 | 烟雾浓度超阈值 |
| 4 | 电压异常 | 电压超范围 |
| 5 | 电流异常 | 电流超范围 |
| 6~15 | 保留 | — |

> 越限判定由**网关边缘侧**主判（阈值可配置），节点侧仅上报状态；bit1~5 由节点本地简单判定作为冗余，双保险——这个分工面试时可以讲。

### 4.3 从站行为要点

- 只响应 0x03（读保持寄存器），收到非本地址帧丢弃
- 帧校验：CRC16（Modbus 多项式 0xA001），错误不响应（主站走超时重试）
- 从站处理时间：收到请求到发出响应 ≤ 50ms（远小于主站超时 200ms）
- 寄存器区用共享内存 + 关中断保护（采集更新 vs Modbus 读取并发）

## 5. 电气与接线要点

| 项 | 要求 |
|---|---|
| 节点供电 | 5V 输入（MAX485/ACS712/MQ-2 需要），板上 3.3V LDO 供 MCU/SHT30/nRF24L01/DHT11 |
| RS485 | A/B 手拉手总线，两端 120Ω 终端电阻，屏蔽双绞线 |
| I2C（SHT30） | SCL/SDA 开漏 + 4.7kΩ 上拉；SHT30 供电 3.3V |
| DHT11 | 4.7kΩ 上拉，数据线尽量短 |
| MQ-2 | 模块 5V 供电（加热器），AO 分压后接 PA0；预热 60s |
| nRF24L01 | 3.3V 供电，电源加 10~100μF 去耦；天线区远离 MCU 晶振 |
| 共地 | 所有节点与网关共地（无线节点独立供电时也建议共地参考） |
